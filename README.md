##  Featured Projects

###  [Match3 Time Attack](https://github.com/ddlara01/Match3-TimeAttack-Unity)
A vertical match-3 puzzle game built in Unity. Race against the clock, chain combos, and climb the leaderboard. Built with ScriptableObjects architecture, DOTween animations, and a full score-ranking system.  
`Unity` `C#` `DOTween` `Mobile`

---

###  [Orange vs. Mandarin Classifier](https://github.com/ddlara01/yolov8-orange-vs-mandarin)
A real-time fruit detection system trained with YOLOv8 on a custom Roboflow dataset. Achieves **mAP50: 0.794** in controlled conditions with live webcam inference using OpenCV.  
`Python` `YOLOv8` `OpenCV` `Google Colab` `Roboflow`

---

###  [AR Shopping Assistant](https://github.com/ddlara01/AR-ShoppingAssistant)
A mobile AR app built in Unity for shopping malls. Uses image recognition to display contextual information and lets users save personalized discount coupons.  
`Unity` `Augmented Reality` `Mobile` `C#`

---

###  [Google vs Azure Vision Comparison](https://github.com/ddlara01/google-azure-vision-comparison)
A hands-on comparison of Google Cloud Vision and Azure Computer Vision APIs, evaluating their performance across different image recognition tasks.  
`Python` `Google Vision API` `Azure Vision API` `HTML`
